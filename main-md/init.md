# 스텔라이브 팬 게임

## 게임 소개
- 장르: 턴제 / 로그라이크 / 덱빌딩
- 모티브: 림버스(인격?이격?전투) / 라오루(전투) / 유희왕(합 방식) / 슬더스(카드 순환) / 명일방주(맵 구성)

## flow
0. 게임을 실행한다.
1. 화면 로딩. 이후 메인 화면과 함께 중앙 하단에 '게임 시작'와 '스토리 보기'라는 버튼이 존재한다. 스토리 보기의 경우 게임 시작보다 버튼이 작으며, 초기 시작때는 버튼이 비활성화 되어 있다.
2. 1번 사항의 버튼 클릭 시, 3명의 스텔라를 선택 할 수 있다. 해당 스텔라는 '바닐라' 버전으로 선택된다. 바닐라는 '스텔라'와 각 기수를 속성으로 갖고 있다.
3. 이후 전투를 반복하고, 최종 진행 상태에 따라 '스토리 게이지'가 충전되며, 수준에 따라 스토리가 해금된다.

### flow in play / '게임 시작' 버튼을 누를 경우 진행되는 흐름이다.
0. 게임 시작 시, '근토리' 하나가 나온다.
1. 맵은 총 5계층으로 구성되어있다. 3층과 5층에 보스가 존재한다.
2. 맵은 랜덤이며, 아래에서 올라가는 방식이다. 각 node는 전투맵이며, edge는 node와 node를 연결해준다. >> 이거 어캐 구현하지? 음
3. 노드의 종류는 다음과 같다. '일반 전투 노드', '어려운 전투 노드', '이벤트 노드', '상점 노드', '휴방 노드' 각 노드는 다음과 같다.
- 일반 전투 노드: 표준 난이도 전투 노드이다.
- 어려운 전투 노드: 표준 난이도 전투 노드보다 어려운 노드이다. 해당 노드에는 랜덤한 제약 사항이 추가로 붙는다.
- 이벤트 노드: 긍정적 혹은 부정적 이벤트가 발생하는 노드이다. 때론 전투가 발생하기도 한다.
- 상점 노드: 주로 물건을 사거나 파는 노드이다. 소모품이랑 유물 카드 강화.
- 휴방 노드: 휴식으로 체력을 채우거나 이격으로 변경. 혹은 편성을 수정한다.
